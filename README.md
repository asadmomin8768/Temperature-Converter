# Temperature Converter

A simple and user-friendly **Temperature Converter** for converting values between Celsius, Fahrenheit, and Kelvin.

## ✨ Features

* Convert between Celsius, Fahrenheit, and Kelvin
* Instant conversion results
* Simple and responsive interface
* Easy-to-use input controls

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## 📌 Purpose

This project was created to practice **HTML, CSS, and JavaScript** by building a practical temperature conversion tool.
